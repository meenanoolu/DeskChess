# Desk Chess

Hands-first chess on the simulator's sunlit living room table. Ivory and ebony Staunton pieces. Built with the Immersive Web SDK.

## Run

```bash
npm install
npm run dev
```

1. The room is the built-in living room. Nothing extra is placed under the board.
2. Switch input to Gaze + Hands.
3. Put both palms down until the rings fill, or pinch **Place Board Here**. The board sits on the coffee table.
4. **Full Match** is you versus the bot. **Mate in 2**, beside it, is the short puzzle.
5. Pinch an ivory piece and drop it on a green square. Reset starts that mode over.
