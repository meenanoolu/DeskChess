# Desk Chess

Hands-first chess on the simulator's sunlit living room table. Ivory and ebony Staunton pieces. Built with the Immersive Web SDK.

## Run

```bash
npm install
npm run dev
```

1. The room is the built-in living room. The board is already on the coffee table.
2. Switch input to Hands. Drag a hand onto an ivory piece and pinch, or use Gaze + Hands.
3. **Full Match** is you versus the bot. **Mate in 2**, beside it, is the short puzzle.
4. Drop a piece on a green square. Reset starts that mode over.
